# v0.1.0 — Typed durable graph runtime

Introduced the typed coding graph, SQLite checkpoints, bounded cycles, durable state, and a Ralph-style loop baseline for comparison.

## Problem observed

Open-ended agent loops repeated work and had no explicit state or trustworthy stop boundary.

## Result

A runnable 12-node coding graph with durable checkpoints and a measurable loop baseline.
