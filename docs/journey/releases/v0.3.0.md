# v0.3.0 — Real repository execution

Added detached Git worktrees, transactional patch application, bounded commands, real tests, evidence-driven repair, and explicit patch promotion.

Synthetic graph execution did not prove safe behavior against actual repositories and side effects.

## Result

Repository changes became isolated, resumable, testable, and separately promotable.
